# Калькулятор пробега ГСМ — MVP (Этап 1, Шаг 1.1)

Внутренний инструмент для сотрудников «Предрейс»: восстановление путевых листов
по чекам с АЗС. Реализует **Шаг 1.1** технического задания — калькулятор пробега
с построчным текстовым выводом по каждому путевому листу.

Стек: **Vite + React 18 + TypeScript**.

## Запуск

```bash
npm install
npm run dev      # локальный сервер на http://localhost:5173
```

Сборка production-версии:

```bash
npm run build    # результат в dist/
npm run preview  # предпросмотр собранной версии
```

> Требуется Node.js 18+. Путь к проекту должен быть без кириллицы (иначе dev-сервер Vite на Windows может не отдавать модули).

## Структура

```
├─ index.html              # точка входа Vite
├─ package.json            # зависимости и скрипты
├─ tsconfig*.json          # конфигурация TypeScript
├─ vite.config.ts          # конфигурация Vite

   ├─ main.tsx             # монтирование React-приложения
   ├─ App.tsx              # форма ввода + управление состоянием

   ├─ defaults.ts          # начальные и демо-данные
   ├─ styles.css           # стили
   └─ components/
```

Вся логика расчёта изолирована в `src/calc.ts` (чистые функции без React) —
её можно переиспользовать на шагах 1.2 и 2.x без изменений.

## Формулы и модель расчёта

**Пробег за смену (км) = затраты ГСМ за смену (л) × 100 / средний расход (л/100км)**

Средний расход определяется так:
1. **Спецтехника** — коэффициенты не применяются, расход задаётся вручную (обязателен).
2. Иначе базой служит ручной «Средний расход», а если он пуст — норматив по
   умолчанию для вида топлива. К базе применяются коэффициенты-надбавки.

### Коэффициенты (ориентированы на Распоряжение Минтранса АМ-23-р)

| Фактор | Надбавка (MVP) |
|--------|----------------|
| Зима (ноябрь–март) | +10% |
| Возраст ТС > 10 лет | +5% |
| Прицеп/груз | +10% |
| Городское сообщение | +10% |
| Пригородное сообщение | +5% |

### Ограничения (по ТЗ)

- Остаток в баке на конце ≥ 10 л; `остаток + заправка` не превышает объём бака.
- Суточный пробег: до 300 км (легковой) / до 250 км (грузовой).
- Если одометр на начало неизвестен — расчёт стартует от 2500 км.

## Допущения MVP (требуют согласования)

- Тип ТС (легковой/грузовой) добавлен как поле — нужен для лимита пробега.
- Время выпуска по умолчанию 08:00; время в пути — по средней скорости.
- «Факт» расхода приравнен к распределённым затратам топлива.
- Справочник норм по моделям и точные коэффициенты — на шаг 1.2+.

(1 ТС, 2 водителя, июнь, 12 заправок).
