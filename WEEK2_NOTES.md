# Неделя 2: тестирование формул + алгоритм маршрута

## Что сделано

**Тестирование и отладка формул**
- `backend/tests/test_calc.py` — 40 юнит-тестов на `pytest`, покрывают:
  - коэффициенты (зима по месяцам ноябрь–март, возраст >10 лет, прицеп/груз,
    вид сообщения, суммирование нескольких коэффициентов, спецтехника
    игнорирует все коэффициенты);
  - валидацию схемы (спецтехника без расхода, период задом наперёд, без
    водителей, межгород без срока рейса, заправка вне периода);
  - генерацию смен (`build_shifts`): один ПЛ на рабочий день, round-robin
    между водителями, группировка многодневного рейса в один ПЛ;
  - `calculate()` целиком: лимиты суточного пробега (300/250 км), минимальный
    остаток в баке на закрытии, ограничение заправки объёмом бака,
    поведение при отсутствии рабочих дней, старт одометра с 2500 км,
    непрерывность одометра между путевыми листами.
- Все тесты зелёные: `pytest -v` → `40 passed`.

**Алгоритм построения маршрута по адресам АЗС**
- В схему добавлены (все поля опциональны — старые запросы недели 1
  продолжают работать без изменений):
  - `Заправка.адрес` — адрес АЗС из чека;
  - `ВходныеДанные.адресСтоянки` — точка отправления/возвращения ТС;
  - `ПутевойЛист.маршрут` — список адресов для данного путевого листа.
- Алгоритм (`backend/app/calc.py`, функция `calculate`): для каждого
  путевого листа маршрут строится как
  `[адрес стоянки] → [адреса АЗС из чеков, применённых к этой смене, в
  хронологическом порядке] → [адрес стоянки]` — по образцу примеров из ТЗ
  (раздел «Маршрут»).
- Вне рамок этого шага (по плану — недели 3+):
  - геокодинг адресов (Яндекс.Карты API);
  - валидация «АЗС вписывается в маршрут» (проверка по факту, не только
    последовательность);
  - промежуточные рабочие адреса (погрузка/разгрузка, частотные адреса
    организации) — потребуют отдельного поля ввода на фронте.

## Как проверить

```bash
cd backend
pip install -r requirements.txt
pytest -v
```

Пример запроса с адресами — см. `README.md` бэкенда, поле `адресСтоянки` в
`ВходныеДанные` и `адрес` в каждой `Заправка`.
