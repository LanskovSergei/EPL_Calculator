# Неделя 1: алгоритм расчёта + бэкенд API

## Что сделано

**Алгоритм расчёта (коэффициенты Минтранса, АМ-23-р)**
- Логика 1:1 портирована из `src/calc.ts` (фронт) в `backend/app/calc.py` —
  фронт и бэкенд считают одинаково, числа сверены на тестовых сценариях.
- Коэффициенты: зима (+10%), возраст ТС >10 лет (+5%), прицеп/груз (+10%),
  вид сообщения (городское +10%, пригородное +5%).
- Ограничения: остаток в баке на закрытии ПЛ 10 л – объём бака; суточный
  пробег 300 км (легковой) / 250 км (грузовой); старт от 2500 км, если
  одометр на начало не задан.
- Спецтехника: коэффициенты отключены, средний расход — только вручную.

**Бэкенд API (FastAPI)**
- `POST /api/calculate` — принимает те же поля, что форма фронта (имена
  полей кириллицей, 1-в-1 с `src/types.ts`), возвращает путевые листы +
  предупреждения + сводку по расходу.
- `GET /api/health`.
- Валидация на уровне pydantic: обязательные поля, диапазоны значений,
  `периодПо ≥ периодС`, спецтехника требует ручной расход, минимум один
  водитель, для межгорода/межнара — срок рейса, даты заправок и рабочих
  дней водителей — в пределах расчётного периода. При ошибке — 422 с
  человекочитаемым списком сообщений.
- CORS настроен на Vite dev-сервер (`ALLOWED_ORIGINS` в env).

## Структура добавленных файлов

```
backend/
├─ README.md
├─ requirements.txt
└─ app/
   ├─ main.py      # FastAPI app, CORS, обработчик ошибок валидации
   ├─ routes.py     # POST /api/calculate, GET /api/health
   ├─ schemas.py    # pydantic-модели входа/выхода
   └─ calc.py       # движок расчёта (порт src/calc.ts)
```

## Как проверить локально

```bash
cd backend
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000
# затем: http://localhost:8000/docs
```
