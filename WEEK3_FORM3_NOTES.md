# Неделя 3: генерация путевого листа форма №3 (легковой)

## Что сделано

- **Схема запроса** (`app/schemas.py`): `ЗапросФормыПЛ` — исходные данные
  калькулятора (`расчёт`) + документные реквизиты для печати:
  `ДанныеОрганизации`, `ДанныеТСДокумент`, `ДанныеВодителяДокумент`,
  `ДанныеПрицепа`, `ТипПеревозки` (по заказам / для собственных нужд),
  `ПоляДляПечати` (чекбоксы «что заполняем в сервисе» — ТЗ Шаг 2.2:
  «блок заполняемости полей»). Валидация: форма №3 — только для
  `типТС: легковой`, для грузового вернёт понятную ошибку 422 (форма
  №4-с — следующий шаг, не в этом объёме работ).

- **`app/forms.py`** — генерация:
  - `generate_form3_excel()` — книга `openpyxl`, один лист на путевой лист,
    поля сгруппированы по блокам (организация / ТС / водитель / тип
    перевозки / работа и ГСМ / маршрут), уважает чекбоксы из `поля`.
  - `generate_form3_pdf()` — `reportlab`, одна страница на путевой лист,
    та же группировка полей.
  - Кириллический шрифт **DejaVu Sans** зашит в `app/fonts/` и
    зарегистрирован в reportlab — без этого PDF показывал бы вместо
    кириллицы чёрные прямоугольники (встроенные PDF-шрифты Helvetica её
    не содержат).
  - Дисклеймер про мед. осмотр/техконтроль печатается на каждом листе.

- **Эндпоинты** (`app/routes.py`):
  - `POST /api/form3/excel` → `.xlsx`
  - `POST /api/form3/pdf` → `.pdf`
  - Если после расчёта нет ни одного путевого листа — 422 с пояснением
    (а не пустой/битый файл).

- **Тесты** (`tests/test_forms.py`, 8 шт. + `tests/test_api.py`, +3 на
  эндпоинты): проверка количества листов/страниц, наличия ключевых полей
  в содержимом (название организации, гос. номер, ФИО, адрес АЗС в
  маршруте), работа чекбоксов «что печатать», отказ для грузового ТС,
  корректный content-type и что файл действительно PDF/xlsx.

Итого тестов в проекте: **68**, все зелёные.

## Как проверить

```bash
cd backend
pip install -r requirements.txt
pytest -v

uvicorn app.main:app --reload --port 8000
# затем POST на /api/form3/pdf или /api/form3/excel с телом ЗапросФормыПЛ
# (пример тела — см. tests/test_forms.py::make_form_request)
```

Живой пример PDF (2 путевых листа, реальный сгенерированный файл) —
`putevoy-list-forma-3-sample.pdf`, приложен отдельно.

## Не входит в этот шаг

- Пиксель-в-пиксель копия официального бланка Госкомстата — сейчас это
  функционально полный, но упрощённо свёрстанный документ со всеми
  обязательными реквизитами; визуальное приближение к бланку — отдельная
  задача (брендирование, Шаг 1.2/2.2 UI).
- Форма №4-с (грузовой) — по плану следующим шагом.
- Валидация чеков через ОФД, интеграция с 1С — по плану, недели 4–5.
